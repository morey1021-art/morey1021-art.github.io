Pin TOEFL iOS 背單字 App v2

資料
- 閱讀單字：1181 個
- 聽力單字：493 個
- 合計：1674 個
- 中英對照，維持原單字本章節與順序

新增功能
1. 上一個／下一個
2. 單字點讀：點單字只唸一次，播完停止
3. 連續播放：由目前單字開始往後播放
4. 0.75× / 1× / 1.25×
5. iPhone 美式英文語音選擇
6. ⭐ 收藏單字
7. ✓ 已背／未背標記
8. 篩選：全部、收藏、未背、已背
9. 原本順序／A-Z 排序
10. 隨機四選一測驗
    - 英文 → 中文
    - 中文 → 英文
    - 閱讀＋聽力 / 只考閱讀 / 只考聽力
11. 測驗答對會自動標記為已背
12. 收藏、已背與測驗成績使用瀏覽器 localStorage 保存

iPhone 使用
- 若只想快速開啟，可用「Pin_TOEFL_iPhone_背單字App_v2_單檔版.html」。
- 若要像 App 一樣加入主畫面，將 ZIP 解壓後放到 HTTPS 網站空間，
  用 iPhone Safari 開啟 index.html 對應網址，再按：
  分享 → 加入主畫面。
- PWA 離線快取需要 HTTPS。
